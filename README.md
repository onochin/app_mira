# MIRA 3D表示の試作

`261113` の45測定断面を使い、ミラを縦に保持して横へ100 mmずつ移動した配置を試すものです。設定アプリの完成版ではありません。

## 今後の設定アプリの要件

- **自由回転**：3D表示をマウスでドラッグして、任意の角度から見られるようにする（「グリグリ」回す操作）。試作には回転処理を実装済みで、ブラウザー実画面での動作確認は未実施。
- **補間のオン／オフ**：試作に実装済み。初期状態はオフ。オンでは隣り合う測定断面の表示強度を線形補間し、100 mm間隔を10 mm刻みで表示する。ブラウザー実画面での動作確認は未実施。

補間オンの表示では、測定されていない断面間を推定していることが分かるようにする。補間で実際の測定分解能が向上するわけではない。

測定高さの基準（上端99 cm）、赤丸付近の見かけの位置差、複数の反射と表示条件の切り分けは、[懸案事項](docs/懸案事項.md)に記録しています。原因は未確定で、位置補正は行っていません。

## 開き方

`MIRA_3D試作.html` をChromeまたはEdgeで開きます。追加インストール・サーバー起動・ネット接続は不要です。HTMLと`prototype`フォルダは一緒に置いてください。

チャット内の画像と`prototype/3D_preview.png`は静止画です。回転して見るには、既存のHTMLを開いて3D画面を左ドラッグしてください。別のHTMLアプリを新規作成する必要はありません。

GitHubから取得したコードには測定データと生成データは含みません。先にローカルの`261113`フォルダを配置し、`python tools/build_probe.py`を実行してからHTMLを開いてください。

- 3D画面を左ドラッグ：回転
- ホイール：拡大・縮小
- Shift＋ドラッグ：移動
- 「表示する強度の下限」：弱い表示強度を非表示にする
- 「不透明度」「表示する深さ」：表示範囲を確認する
- 「測定位置」：元の断面と測定位置を確認する
- 「元のBMP」：記録された機器画面を開く
- 「高さを反転」：装置の上下が仮置きと逆だった場合に切り替える
- 「断面間を補間」：測定断面のみの表示と、断面間を線形補間した表示を切り替える
- 「測点目盛り（10cm）」：3D表示と下部の投影図に、実測位置ごとの100 mm間隔の短い目盛りを表示する（初期状態はオン）

全測点への白い断面枠は、反射像に線が重なって見にくいため採用せず、短い目盛りの表示に戻しました。右側に表示中の断面だけを黄色の少し太い枠（2.5 px）で示します。目盛りを非表示にしても選択中の黄色い枠は残ります。補間をオンにしても、目盛りは全45か所の実測位置のままです。横位置の数値（mm）とc番号は表示幅に応じて間引きます。

ブラウザーでのGPU描画・操作は、この作業環境ではまだ実画面で確認できていません。`prototype/3D_preview.png` は、同じ実データを独立したPython処理で配置・描画して確認した静止画です。

## 確認できたこと

- `.bin` は1断面296×432点、1点4バイトのリトルエンディアン整数でした。このデータの値は0〜254です。
- 各深さ行の296点を左右反転すると、BMP内の断面画像（左294、上42、幅296、高さ432）と対応します。
- 元BMPから得たカラーテーブルで45断面すべてを照合し、カーソル線を除く **5,721,525画素が完全一致**しました。
- 45×296×432＝5,754,240点の保存済み表示強度を読み込んでいます。画面の文字やカーソル線を立体化しているわけではありません。
- データは外部送信しません。元ファイルを変更しません。
- 照合の詳細と元ファイルのSHA-256は`prototype/verification.json`にあります。

## 座標と未確認事項

| 項目 | 今回の扱い |
| --- | --- |
| 横位置 | c1を0 mm、c45を4,400 mm、番号順に100 mm間隔で配置 |
| 高さ | 元の断面Xを壁面の高さ方向へ配置。測定中心を0 mmとする相対座標、範囲−257〜＋257 mm |
| 深さ | 元画面・cfgに対応する0〜750 mm |
| 上下 | 元画面X＋を上に仮置き。「高さを反転」で切替可能 |
| 測定順・高さ | c番号が連続する測定順で、装置の中心高さは一定と仮定。現地記録との照合は未実施 |
| 断面間 | オフ：100 mm間隔の45測定断面。オン：線形補間で10 mm刻みの441断面（実測45＋推定396）。測定のない隙間の形状が確定したわけではない |
| 強度 | 保存済みの表示強度0〜254。dB、欠陥確率、校正済み絶対振幅ではない |
| 断面ごとの設定 | cfgの一部に差がある。ゲイン等の項目の正式な対応、断面間の振幅校正は未確認 |
| 音速 | 機器が記録した断面をそのまま使用。音速変更による再構成はしていない |
| 欠陥判定 | 反射の原因、実際の欠陥形状・寸法の判定はしていない |

横方向100 mmの取得間隔と、断面内の細かな画素間隔は異なります。表示が細かく見えても横方向の測定分解能が向上したことにはなりません。

## 使用する技術・ライブラリ

| 用途 | 使用するもの | 外部パッケージ |

| 3D表示・回転・透明度 | JavaScript、ブラウザー標準のWebGL 2 | 不要 |
| 断面画像・目盛り・投影表示 | ブラウザー標準のCanvas 2D API | 不要 |

補間機能も既存のJavaScriptとWebGL 2で実装しており、追加ライブラリは不要です。

## 補間表示の扱い

- 初期状態は補間オフ。オン／オフの切替えで視点・選択断面・強度下限などの設定を保ちます。
- オンでは同じ高さ・深さの隣接する値を位置に応じて線形補間します。色や、すでに投影した最大値同士を補間する処理ではありません。
- 3Dと「横位置 × 深さ」の投影に反映します。投影は補間した値から高さ方向の最大値を計算します。
- 右側の「選択した断面」と「元のBMP」は常に元の測定断面です。
- 補間断面が増えた分、3Dの不透明度を補正して見かけの濃さの増加を抑えます。
- 元ファイルと`prototype/data.js`は変更しません。補間した値はメモリー上で表示するだけで、外部送信・ファイル保存は行いません。

## GitHubとローカル保管の範囲

- GitHub：HTML、CSS、JavaScriptのコード、Pythonスクリプト、READMEなどのドキュメント。
- ローカルのみ：測定データ、測定データを含む生成JS、検証結果、生成プレビュー画像。
- `.gitignore`で`data/`、`261113/`、`local_notes/`、測定ファイル名のパターン、`prototype/data.js`、`prototype/verification.json`、`prototype/*_preview.png`を除外しています。Gitの除外設定は、ローカルファイルを削除しません。
- 異なる名前の測定データを追加するときは、アップロード対象に含まれないかを事前に確認してください。

## 再生成・検証

```powershell
python tools/build_probe.py
node --check prototype/viewer.js
node tools/check_interpolation.cjs --real-data
python tools/render_preview.py
```

データ変換・BMP照合はPython標準ライブラリだけで動作します。静止画生成だけは、このPCにすでにあるPillowを使用しています。追加パッケージは導入していません。

`check_interpolation.cjs`は既知の人工データで補間値と投影の計算順序を確認し、`--real-data`指定時は実データで実測点の保持、切替え、視点や設定の保持も確認します。模擬DOM/WebGL APIを使用するため、GPUの実描画やGLSLコンパイルを検証するものではありません。測定データなしでも人工データのチェックは実行できます。

変換は実データの配列とBMP照合から確認したものです。`.lbv`の生波形からの再構成、`.sin`/`.cos`を用いた振幅処理は本試作の対象外です。
