# MIRA表示・解釈の懸案事項

記録日：2026-11-16。現時点の観察、ユーザーからの測定条件、資料で確認した一般事項、未検証の仮説を区別して記録する。原因の断定や位置補正の実施を意味しない。

2026-11-20：フォルダ読込版を今後の基本版とし、旧固定データ版2つは`archive/`へ移動した。以下の懸案事項は基本版に引き継ぐ。添付画像は旧固定データ版で確認したものである。

## 1. 測定高さの基準と各断面の位置ズレ

ユーザー申告の測定条件：橋台コンクリートの壁面でミラを縦に保持し、横へ100 mmずつ移動。高さ方向（ユーザーの表現ではy）は一定に合わせ、「上端の高さ99 cm地点」を基準としていた。測定時に少しズレた可能性があるとの申告。

- 99 cm＝990 mmは現地の基準高さとして記録する。装置上端・断面表示範囲の上端など、どの点に対応するか、および現地の高さ基準点との関係は未確認。
- 現在の試作は全断面を同じ中心高さに配置し、装置の画像Xを相対的な高さ方向としている。99 cmを表示座標の原点・中心・端に変換する処理は未実装。
- 画像だけから測定時の高さズレと断定しない。深さの差、対象の配置や別の反射への見え方の変化、機器条件や表示処理の影響も切り分ける。
- 将来の候補：断面ごとの高さ調整。ただし、自動で明るい点を揃えると、本来異なる対象や実際の配置変化まで揃えてしまう可能性がある。原因を確認してから仕様を決める。

## 2. 添付画像の赤丸付近の反射位置

参照画像：[赤丸を付けた3D表示（ローカル保管）](../local_notes/2026-11-16_reflector_offsets.png)。測定データに由来する画像のため、`local_notes/`はGitHubへの保存対象から除外する。

### 観察と疑問

- 左の赤丸内の明るい部分、右の赤丸内の明るい部分が、近傍の反射の並びより画面上で上方に見える。
- 画像は回転した3D表示の一部であり、画面の上下は現地の高さ方向とは限らない。どの座標成分が変化したか、位置差が何mmかは、この画像から確定していない。
- 赤丸が指す実測ファイル番号（c番号）、撮影時の視点、補間状態、強度下限、不透明度、深さ範囲は未特定。
- 赤い反射が鉄筋であるか、近傍と同じ鉄筋・同じ列に属するかは未確認。強い反射位置をそのまま鉄筋中心と扱わない。

ユーザーの疑問：上にも鉄筋などがある場合、そちらの強い反射に影響され、本来連続して見えるはずの下側の反射が表示されにくくなることはあるか。

### 資料で確認した一般事項

1. **最強の1点だけを選ぶ装置ではない。** A1040 MIRAのメーカー資料では、複数の送受信ペアの情報をSAFT-Cで合成し、各位置の反射の強さを色で表すと説明している。断面内に複数の反射を表現できる。[メーカー操作マニュアル、印刷ページ15、1.3.2](https://acs-international.com/wp-content/themes/Divi-2/download/10%20A1040%20MIRA/Operation%20manual.pdf)
2. **強い反射体の奥は捉えにくい場合がある。** A1040 MIRAを用いた実験論文は、反射体より奥の領域の検出性低下を扱っている。超音波経路の手前にある反射体により奥側の信号が弱くなる可能性と、画面上で単に上に見えることは分けて考える。[Kwonほか、Sensors 2021、Introduction](https://www.mdpi.com/1424-8220/21/19/6681)
3. **強い別の反射があると鉄筋の反射が目立たなくなる場合がある。** MIRA 3D Proの実験では、剥離部の強い反射によって鉄筋が見えにくくなる例が報告されている。別世代の機器・別の供試体の結果であり、今回の原因を証明するものではない。[Infrastructures 2023、5.2.3](https://www.mdpi.com/2412-3811/8/3/53)

「上の反射に引っ張られる」は現時点では仮説として扱う。壁面で上下に離れた鉄筋があるだけで下側が隠れるとは判断できない。実際の深さ、送受信の経路、反射同士の重なりや分離のしやすさを確認する必要がある。

### 今回の試作で確認した表示処理

- 3D表示は保存済み断面の強度を使い、最強の1点のみを追跡・選択する処理はしていない。
- 強度下限未満の点は3Dで非表示になる。不透明度と視点によって、重なった別の反射が見えにくくなる可能性がある。
- 下部の「横位置 × 深さ」は、各横位置・各深さで高さ方向の最大値を表示する。高さ方向を畳み込む表示であり、異なる高さの反射をこの投影図だけで区別することはできない。ただし、全深さから1点だけ選ぶ処理ではない。
- 補間は同じ高さ・深さの隣接値を線形につなぐ。対象物を認識して対応付ける処理や位置ズレ補正ではない。隣の断面で別の反射が優勢なら、それらの間にも推定値が生じる。
- 右側の「選択した断面」と元BMPは測定断面のまま。表示下限や3Dの不透明度によって切り捨てていない。
- `.bin`の0〜254は保存済みの表示強度であり、校正済みの絶対振幅ではない。cfgの一部は断面間で異なるが、各キーとゲイン・音速設定等との正式な対応、および影響は未評価。

## 3. 今後の確認手順と未解決項目

まず表示上の影響を確認し、その後に測定・反射そのものの違いを検討する。

1. 赤丸と実測c番号を対応付け、前後の測定断面と元BMPを並べて確認する。対応は目視の印象だけで決めない。
2. 補間オフでも位置・形状の差があるかを確認する。補間した領域と実測点を区別する。
3. 視点を変え、壁面の高さ方向と深さ方向のどちらの差かを確認する。
4. 強度下限を下げ、不透明度を変え、期待する別の位置に弱い反射が残っているかを確認する。現在の深さ表示範囲から外れていないかも確認する。
5. 反射の候補を複数残して比較する。「一番明るい点＝同じ鉄筋」という対応付けを前提にしない。
6. 必要ならcfgの設定差と機器マニュアルの対応を調査し、`.lbv`などの元波形や再構成条件の調査へ進む。現状の試作は生波形から再構成していない。
7. 配筋図・現地記録・機器の向きや接触条件・再測定等と照合して、位置ズレ、実際の対象配置、影や反射の重なりを切り分ける。再測定はこの依頼では実施していない。

現在の結論：**赤丸に見かけ上の位置差はあるが、測定時の高さズレ、別の反射体、強い反射の奥の検出性低下、表示条件のどれが原因かは未解決。高さ補正や自動位置合わせはまだ実施しない。**
